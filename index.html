Resumo

    Conecte suas redes

    Cada rede conectada passa a aparecer no painel. A conexão é somente leitura: o painel só lê os números, nunca publica nem apaga nada.

    Bloqueio por PIN

    Protege o painel de quem usa o seu computador ou celular. Com o PIN ativo, o painel bloqueia sozinho após 5 minutos sem uso.

    O PIN protege contra quem olha a tela ou pega o aparelho. Para uma proteção forte, a versão final precisa de login em servidor.

    Como o painel protege seus dados

      Use o botão “Ocultar números” no topo antes de compartilhar a tela em uma reunião.

      LGPD e dados pessoais

      • Comentários de seguidores podem ter nome e outros dados pessoais. Na versão final, o painel mostra só totais, sem nomes nem textos completos.
      • Colete apenas o necessário para a finalidade combinada (princípios da Lei nº 13.709/2018).
      • Os dados dos clientes seguem as regras do contrato firmado com cada um.

      Se algo der errado

      1. Desconecte todas as redes na aba Conexões e troque as senhas delas.
      2. Troque o PIN e apague os dados deste aparelho (botão abaixo).
      3. Avise os clientes envolvidos e anote o que aconteceu, quando e quais dados foram afetados.
      4. Se houver dados pessoais, avalie com apoio jurídico a comunicação à ANPD e aos titulares, como pede a LGPD.

      Dados salvos neste aparelho

      O painel guarda só quais canais estão conectados e, se você ativar, o resumo criptografado do PIN. Nunca guarda senhas das redes.
